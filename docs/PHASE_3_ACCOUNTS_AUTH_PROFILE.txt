2. USER STATUS RULES IN PLACE
-----------------------------

New registered users start with:

- Account status: locked.
- Activation status: not activated.
- KYC status: not required.

This supports the planned activation flow in later phases.


3. LOGIN IDENTIFIERS
--------------------

Users can authenticate with:

- Username.
- Email address.
- Phone number.

Phone numbers are normalized into Kenyan international format where possible.


4. IMPORTANT LIMITS
-------------------

Phase 3 does not yet include:

- Email verification.
- SMS OTP.
- Password reset email flow.
- Activation payment.
- Withdrawal KYC.
- Fraud device checks.

These belong to later security/payment phases.
